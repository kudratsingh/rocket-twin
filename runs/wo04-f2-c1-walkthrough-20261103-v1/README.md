# F2-C1 recorded connection drawings

Actual React/SVG exports rendered through the existing native Mac AppKit route.
The first graph had port/label problems. One visual correction was inspected;
subsequent metadata/source refreshes preserved visible SVG hashes.

`record.json` pins the final specification, saved calculations, producer and
actual local PNG/SVG hashes. The earlier render records preserve diagnostic
attempts. These are offline observations, not browser screenshots, clicks,
download or engineering acceptance. Bulk images remain in
`output/engineering-f2-c1`; regenerate with `make workbench-f2-c1`, then
`node scripts/wo04_export_f2_c1_drawings.mjs`. No solver reruns are involved.

See `docs/wo04-f2-c1-walkthrough-20261103.md` for startup, cases and limitations.
