# Inspection camera framing — 2026-11-07

`fitOrbitFrame` fits the supplied world-space axis-aligned box in the current viewing direction, retaining the six-argument call. An optional seventh argument is `{ insets: { left, right, top, bottom }, fill }`. Each inset is a fraction of the full canvas width or height, with zero defaults; `fill` is the allowed fraction of each dimension of the remaining safe rectangle. The default `fill` is `1 / 1.15`. Insets must be nonnegative and leave positive width and height; fill must be in `(0, 1]`. Invalid bounds or perspective inputs throw `RangeError`.

The fitter checks the actual perspective depth of every box corner, finds a distance and lateral target offset that contain them inside the safe rectangle scaled by `fill`, then centers the projected box extrema within that rectangle. Insets can shift the orbit target away from the box center. Camera direction is preserved; a stable fallback handles a parallel or zero up vector. The former 0.05 m minimum distance is removed; tiny parts have scale-appropriate distances and near/far planes. A point box uses a small numerical fallback so its frame remains finite.

For a side-on, height-limited assembly, `fill: 0.85` targets 85% of safe height. For part framing, `fill: 0.75` or `0.8` targets the limiting projected box axis and leaves at least 10% safe-rectangle clearance on both sides of either axis. Other aspect ratios, orientations and conservatively oversized bounds can prevent a **rendered mesh** from meeting a requested occupancy. Insets should represent actual reserved overlay space; final fit and clearances still need browser pixel-rectangle verification after asset load and layout changes.

`clippedBoxBounds(box, plane)` bounds the intersection of the **input box** with the nonnegative plane half-space, consistent with `isPointClipped`; `null` means the input box lies entirely in the clipped half-space. This is conservative bounding-box display math, not mesh/plane intersection. It cannot prove that any drawable geometry survives the cut and must not be presented as a tight fit to sectioned visible geometry. The caller must account for visibility, world transforms, explosion and input source identity; no actual browser, GLB, CAD, physical or flight acceptance is implied.

Focused node tests exercise perspective corner containment and centering in asymmetric safe insets, a 1.2 m slender box, a 0.5 mm part, wide aspect, end-on and parallel up, degenerate boxes, expected scale, and box/plane intersections. Existing inspection-camera tests remain in scope.
