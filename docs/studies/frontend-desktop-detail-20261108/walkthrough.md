# RP1 desktop inspection walkthrough

This is a source-backed desktop inspection path, with [native image gallery](gallery.html). It is useful for seeing recorded geometry and missing detail; it is not a finished CAD, installed-fit, or flight review.

## Open the recorded design

From the repository, run `make preview`, then open the normal frontend at [RP1 Design](http://127.0.0.1:5173/?workspace=design&design=G80-F2-RP1-AD1-definition-v2&spec=811b3bed631fe2ce30a6b0211beecb739d40ebbbcb10e063f6beba0854631660&part=forward_ring). The frontend is on port 5173; port 8000 is the API. Keep the displayed configuration `G80-F2-RP1-AD1-definition-v2` and specification SHA-256 `811b3bed631fe2ce30a6b0211beecb739d40ebbbcb10e063f6beba0854631660`. This link selects `forward_ring`; the saved source has 55 records, comprising 10 source-dimensioned shapes, 16 simplified envelopes, 25 non-spatial allowances, and four missing geometries. Only 26 records have inspection meshes. The forward ring is a **simplified inspection envelope**, with finished manufacturing geometry unavailable.

## See the geometry and evidence

1. In **Design → Detail coverage**, choose **Inspect modeled detail** for the forward ring. The P35 native action framed the ring and isolated it to 1 of 26 meshes, but left the coverage disclosure open. The corrected P36 native action [automatically closed it](../../../runs/frontend-desktop-step-native-20261108/inspect-corrected.jpg) without manual cleanup. The [final P36 view](../../../runs/frontend-desktop-step-native-20261108/final-step-detail.jpg) shows the annulus, bore, straight inner-edge notch and thin layer seam. **Restore visibility** returns the prior displayed set.
2. Select **Adjust section cut** to open Scene tools and enable Section. Choose **150°** under **Along the rocket**. P34 native controls and the [150° image](../../../runs/frontend-desktop-cut-native-20261108/rotation150.jpg) establish a changed clipped silhouette. The overview camera did not resolve the ring layers or notch in that packet. Source controls also offer offset, reverse side and across-rocket station; those branches still need their own native observation.
3. For a selected, visible supported part, use **Scene tools → Recorded 3D dimensions** and choose one source guide. P35 selected the ring's nominal **31.9 mm bore** and observed its label and source locator. The menu also showed 12.2 mm stock/bond stack and 4.5 mm proposed notch width. These are recorded nominal values, not measurements from the rendered solid. The [initial P35 guide image](../../../runs/frontend-desktop-detail-native-20261108/bore-guide.jpg) preserves the popover and large-card obstruction. P36 observed the corrected compact two-line label and visible guide line, leaving the central geometry readable. It did not numerically measure endpoints or qualify manufactured geometry.
4. Open **Details → 3D geometry files** for the selected part. P35 observed **Download inspection GLB** return “Mesh hash verified; browser download requested,” then clicked the geometry provenance JSON action. The GLB is the frozen, placed inspection mesh in metres; it excludes optional detail and display transforms. P35 recorded the request; see its [native record](../frontend-desktop-detail-native-20261108/browser.md) for the download attribution limit.

## CAD files and remaining native scope

The **Inspection CAD · STEP** action and provenance appear in the same geometry-files area. The [completed CAD packet](cad-export.md) reconstructed 26 mesh-bearing records as 36 nominal solids, plus a nine-record joint and whole inspection assembly, with readback and hashes. STEP uses **millimetres** and a **nose-tip CAD datum**: X = body +y, Y = body −z, Z = station aft. The viewer GLB uses **metres** and a different frame; the documented mapping is `[CAD X/1000, length_m − CAD Z/1000, CAD Y/1000]`. Treat these as distinct coordinate conventions when opening either file. P36 natively observed the STEP control and clicked part STEP and provenance; [fresh download verification](step-download-verification.json) independently matched both files to registered hashes. That is separate from the offline readback of all 26 records and does not establish manufacturing fit.

For a portable local set, open the [inspection pack index](../../../output/rp1-desktop-inspection-pack/index.html) or [download the ZIP](../../../output/rp1-desktop-inspection-pack.zip). The [pack record](inspection-pack.md) verifies 66 files and gives the ZIP SHA-256; these generated outputs remain local and ignored by Git, so the links work only where the pack exists. P37 separately observed the high-g source PCB/table, selected-placement JSON download and Escape/focus return; [fresh export verification](board-download-verification.json) matches its source and four hole coordinates. It retains the manufacturer 2D XY frame and nominal holes; it supplies no installed vehicle datum, component heights or 3D board fit.

The existing source-labelled 2D board, part drawings, Experiments, replay, comparison and Analysis remain available. Experiments require complete recorded configurations; RP1 has no admitted complete flight inertia/aerodynamics, so its inspection geometry does not enable an RP1 flight prediction.
