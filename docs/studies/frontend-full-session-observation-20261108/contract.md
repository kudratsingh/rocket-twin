# Full-session playback observation contract

The pure recorder in `web/src/experiments/playbackSessionCapture.ts` accepts one immutable-at-start source context: exact primary/comparison run IDs and supplied hashes, playback data profile, speed, optional alignment, first observed UI cursor and supplied monotonic wall start. The caller appends actual RAF intervals and cached observations of the UI cursor, document visibility, window focus and canvas intersection fraction. It can also record visibility, focus, resize and intersection events between frames. The caller supplies the last observed UI cursor and monotonic wall end at snapshot. These are observations, not inferred simulation time or coverage.

The recorder stores at most 24,000 RAF intervals (about 192 kB of numeric interval values before per-frame observation metadata). It reports observed/stored/overflow counts, keeps invalid intervals as `null`, and makes a capped or invalid interval capture ineligible for the mean-target verdict. Raw frame records and event records retain observed state; missing visibility, focus or intersection is `null`, never zero or visible. Event history has a separate explicit 24,000-event cap. It computes mean, p50, p95 and maximum from **all stored valid intervals**, with a strict unrounded comparison against `1000/60` ms only when all observed intervals were stored and valid. One large gap remains in the calculation. Wall duration uses supplied monotonic timestamps; cursor range is the supplied UI observations. The report lists condition failures, including cap, invalid values, unknown and actual hidden/unfocused/partial-canvas states from frames or events, actual resize events, and missing first/last cursor observations. These conditions do not change the separate timing verdict.

This instrumentation adds a full-session evidence path beside the existing rolling-600 diagnostic; it does not modify that diagnostic, saved telemetry, model physics, drawing, replay time or source identities. A mean target result is **not** automatic RV-Q30 acceptance. RAF intervals do not establish GPU completion, and a full benchmark additionally needs the exact ≥120 s/1 kHz full-recovery fixture, declared host/viewport, visible scene, load/memory/scrub evidence and the unchanged 60 fps criterion. Historical native failures and stopped packets remain unchanged. A separate primary-owned bounded native qualification packet is required after source integration. No browser, simulation or physical work was performed for this pure recorder.

Focused synthetic tests cover constant 16 ms, 16.7/17.5 ms target misses, a large gap, missing visibility, invalid intervals, cap overflow and context immutability. They verify the recorder contract; they are not browser or performance evidence.
