## Final read-only reaction and quadratic-connectivity checks

The primary checked the [CalculiX 2.23 manual](https://www.dhondt.de/ccx_2.23.pdf), §§6.11.5 and 7.99: `RF` is an external nodal-force quantity that includes applied forces and reaction forces. This deck has no `DLOAD`, no concentrated load at a `SUPPORT` node, and no explicit MPC or transformation cards. Under those stated conditions, and absent another hidden contribution or output-interpretation issue, the support values are expected to represent support reaction. This interpretation makes the discrepancy material; it does not by itself prove a CalculiX defect or explain the one-MPC solver-summary entry.

A final read-only pass compared all six nodes of the quadratic triangular faces shared by each G11/epoxy pair. Each film had **114–116 matching faces**, with zero mismatched midside-node sets or ambiguous corner-face records. All **1,574** support nodes had exactly zero reported displacement components in both native steps; no applied-load node was in the constrained support set. The primary's separate [midside geometry check](../build/wo03-g80-bridge-area-budget-coarse-v1/root-midside-check.json) found a zero median deviation from each expected straight-edge midpoint across all six edge positions; curved edges had maximum deviations up to 0.2212 mm. These checks do not prove all element behavior or explain the missing force.

For a limited Jacobian check, the saved node coordinates and element connectivity were loaded into an in-memory Gmsh discrete model, with **no mesh generation**, and the existing Gmsh Jacobian API was evaluated at the standard four tetrahedral Gauss coordinates. All **89,980** sampled determinants were positive; the minimum was **0.0008639240722**. This is a pointwise positivity check, not a complete element-quality, conditioning or native stress-point-order validation. Native integration-point ordering and regional stress/energy mapping remain unverified.
