# Replay validity increment

This increment adds a small adapter for legacy experiment records and presents its output for each selected replay. It identifies the run, configuration, recorded controller, simulation code and resolved-specification hashes; missing values remain unavailable. Existing comparison details list different or missing settings and identities. Comparisons use elapsed ignition time, and differences or missing assumptions do not establish a single-factor effect.

The adapter labels a broad phase from event times, explicitly as an inference rather than a recorded state. It lists absent or malformed expected events and distinguishes incomplete, complete and unknown trajectory status. Deployment is a calculated apogee-trigger-plus-lag time in `src/api/experiments.py`, not recorded canopy opening. This does not reconstruct deployment, inflation complete, line loads or separate-body states. Conflicting apogee/deployment times make the phase unavailable. The recorded events are not revised.

`Experiment.tsx` continues to normalize and interpolate the recorded quaternion. `src/sim/frames.py` defines body-to-world orientation and `src/sim/dynamics.py` implements point drag with modeled inflation and angular-rate damping after opening. Current source explicitly says recovery attitude dynamics are not meaningful in this simple model. The presentation does not align the rocket with velocity or infer a real hanging attitude. The saved run's code hash is shown; correspondence between current source and historical code must be independently established. Per-run validity/limitations remain visible, including aerodynamic and sensor limits supplied by the backend.

Integration: import `replayValidity` from `web/src/experiments/replayValidity.ts`, passing the record and selected time. It has no simulator dependencies and does not mutate records. The existing event and comparison interfaces are unchanged. Dedicated tests cover event boundaries, missing/malformed data, controller/source identity, incomplete trajectories and inconsistent event ordering. This increment does not validate telemetry, verify actual Three transforms, add event-state telemetry or establish fidelity of unobserved UI. The designated browser owner must verify presentation and screenshots in the authorized window; no browser observation or acceptance is claimed here. Full WO-03/04/05, engineering, physical and flight gates remain open.
