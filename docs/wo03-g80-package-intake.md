# WO-03 fixed G80 package intake

**Decision:** work toward one complete conventional, fixed-motor G80 package first. The first bounded correction should address the documented motor-mount/aft-shell radial-fit deficit, starting with a source-identity check and a fresh calculation on the exact current G80. A corrected study copy is a proposal; none of the work below adopts it or establishes flight readiness. G54 upgrade work and G12 PID/RL remain committed, independent work, not prerequisites invented for this fixed-motor package.

## Three dependency-ordered deliverables

1. **One G80 fit-correction candidate.** Preflight the current resolved inputs, saved source hashes and exact `aft_shell`/`motor_mount` interface. Execute the existing stack on that identity under its published resource limits before sizing. If the current gap remains deficient, change the fixed frame/shell interface on one separate G80 copy to meet the existing 0.1 mm radial minimum under the full stated tolerance and in-domain expansion stack, with a documented actual worst-case clearance improvement. Regenerate and reconcile only that copy; preserve 42-part accounting, fin-tab channels, motor/liner and retention envelope, support sections, assembly/service and thermal interfaces. Recheck all affected clearances, collisions and mass properties. **Stop** if the exact source stack cannot be reproduced, if required dimensions/CTE are unavailable, if fit conflicts with motor/fin/support integrity, or if the result needs a relaxed criterion. Thermal qualification is a separate dependency, not a reason to claim the fit copy accepted.
2. **Close the same candidate's mechanical load paths.** Quantify thrust and reverse capture through real pads, mount, fasteners and shell; the fin's finite tabs/feet through the slotted shell and fixed frame, including axial root torque, peel, stiffness and the existing 1 mm total deflection budget; and the recovery eye/washer/bulkhead/body and separately routed upper branches. Resolve the actual recovery switch access, controller/cell retention and wiring on the same geometry. Use existing DF3 and method known-case/convergence checks, full recorded loads and explicit hot-property assumptions. **Stop** on missing capacities, unsupported joint/contact or an invalid/nonconverged/capped method; do not claim the historical simplified screens establish these interfaces. Select a correction only if the resulting mass and paths remain compatible.
3. **Qualify heat and revalidate that one full candidate.** First satisfy the published external-tool known-answer and actual-geometry preflight decision, then execute the required G80 heat matrix, including 35°C / 300°C / degraded-foil sensitivity and unchanged material limits. Reconcile every part, adhesive, harness, allowance and full inertia once, and repeat the relevant fit, strength, flutter/stability, guide and JAX/RocketPy checks on the same resolved identity. **Stop** on a failed or unavailable criterion, unqualified thermal method, or a conflicting interface; retain actual findings and replan within the declared budgets. No isolated proposal is a substitute for integrated acceptance.

For later owner involvement, exact motor/case and recovery hardware, supplier data and current club guide/site rules are needed when their interfaces and operating assumptions are fixed; actual material coupons, build, packing, measurements, physical proof, paid runs and flight release remain separate gated actions. This intake made no CAD, FEA, thermal or flight run. The read-only mass check took approximately 0.239 s on the local Python process with thread limits requested; it is an estimated-source property calculation, not a new analysis campaign.
