## What changed

Design uses a compact header, a 56 px workspace rail and an adjacent 264 px
Parts/Details context column. Both left columns collapse independently and retain
reachable openers. There is no permanent right summary. A 42 px closed bottom
strip opens deeper scene, source, layer and component-evidence controls. Focus
restores the previous chrome; keyboard/pointer splitters resize within bounds.
Versioned, validated preferences persist per workspace, with an in-memory
fallback when storage fails. Preferences contain no configuration/run IDs,
physical values, selection or controller state.

The same main visual stays mounted through panel changes. Source-based 2D and
recorded 3D remain distinct. The selected part and source feed tree, visual and
Details. Restore assembly clears display transforms; Exit isolate restores the
visibility map preceding isolation. Hidden/clipped geometry has explicit states.
Source dimensions never change with exploded spacing.

The camera fits actual loaded GLB bounds, excludes helper annotations, and keeps
view direction. Fit assembly includes all cached loaded part bounds; Fit visible
uses the visible part IDs. Both report incomplete coverage. The bounds remain
conservative **full-part boxes**, not a tight clipped-surface measurement. Frame
part uses only that part's mesh record, with explicit Show and frame when hidden
or sectioned. Small-part zoom is no longer limited to a 30–50 mm camera distance.
Fit intent reapplies on canvas resize; manual orbit suppresses unsolicited fit
and late-load resets. The idle canvas uses demand rendering; no frame-rate claim
is made.

Declared safe insets reserve space for toolbars, annotations and axes. Fill
targets are 0.85 for ordinary assembly framing and 0.78 for parts/end-on views.
These are mathematical controls, not observed silhouette measurements. Actual
label bounds, layout proportions, tiny-part orbit and every transition still
need the permitted browser observations. Camera persistence when leaving and
remounting a workspace remains a later cross-workspace integration concern.
