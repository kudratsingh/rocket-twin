# ADR-0014 — Focused frontend engineering workspaces

Date:2026-11-03. Status: accepted owner direction; implementation/verification staged.

The owner provided a43-task planning kit and authorized immediate implementation
with Astra MEDIUM for complex frontend work and Terra HIGH for bounded viewer,
replay and bookkeeping work. Primary retains shared-state/source integration,
engineering decisions and publication. This changes presentation and delivery
priority, not numerical or physical acceptance.

Replace the universal dense shell with Design, Engineering, Experiments, Flight
Replay and Analysis pages. Retain legacy deep links and the current engine,
actual CAD inspection, backend flight execution, saved replay/comparison and
source-linked engineering drawings. Share compatible selection/identity within
a source; never join C1/F1/F2 or old CAD by label alone. Keep current failed and
unavailable fields visible. Use one scrolling content owner and context panels;
keep detailed limitations reachable through compact disclosures.

First implement inspection/navigation and replay-source explanations, then
progress through the dependency ledger. Batch execution, new2D representation,
advanced analysis and measured performance remain separate bounded increments.
No frontend physics or another thermal-solver campaign is introduced.

The existing designated-browser runtime prerequisite remains unresolved. Offline
SVG/AppKit images, source/SSR tests and package builds are separate from observed
browser/WebGL/interaction acceptance. No window, agent or headless/CDP bypass.

References: `output/frontend-planning-kit-20261103/10-agent-start-prompt.md`,
`docs/frontend-workbench-backlog.json`, ADR0009, ADR0013 and `docs/UI.md`.
The local kit is hashed by the ledger; generated ZIP/images are not committed.
G80 construction remains first; G54 upgrade and committed G12 PID-to-RL survive
this UI revision. Every full-WO, owner physical/purchase/paid/firmware/flight gate
is retained.
