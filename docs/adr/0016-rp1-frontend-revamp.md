# ADR-0016 — RP1-first frontend revamp

Status: accepted owner direction, November 7, 2026. UI implementation and browser
acceptance remain separate. This changes presentation priorities, not engineering
criteria or the work-order sequence.

Use the owner's `output/rocket-twin-frontend-revamp-kit-20261106/` and its updated
coding prompt as the implementation brief. Retain the original 43 FT tasks and
evidence; the new 21 RV tasks map to them rather than deleting prior work.

The current design under study is the frozen **G80-F2-RP1-AD1-definition-v2**.
Present its 55 source parts, recorded dimensions, saved cases, drawings and open
findings. Clearly mark estimates and simplified envelopes. A matching complete
CAD assembly, canonical resolved inertia and new flight model are unavailable;
do not substitute historical meshes or simulate this definition by borrowing a
different vehicle. The archived `modular-performance-v1` remains a separate
3D/replay fixture with its own source/run identity. G54 and G12 PID-to-RL remain
separate committed tracks.

The first Design slice has a compact header, two adjacent independently
collapsible left columns, a dominant visual and one bottom tools drawer. Details
replace the permanent right summary. Versioned per-workspace layout preferences
contain UI state only. Focus restores prior chrome without changing source,
selection or camera. Fit, frame, visibility and restore remain explicit actions.

The owner directs implementation to continue from available evidence, without
waiting for supplier or lab replies. **Keep all five inquiry drafts UNSENT.** No
outreach clock starts. VP1 remains an unperformed evidence plan; no purchase,
fabrication, testing or qualification is authorized. Future measurements can
replace estimates only through versioned sources and affected verification.

Default canvas width/height and projected-fit percentages from the kit are
acceptance targets, not measured successes. Only the original designated Terra
owner/window may perform browser verification after supported runtime ownership
is established. The existing block remains; no retry, alternate window,
headless browser or CDP bypass. Publish code/offline evidence while browser rows
remain blocked.

The existing React/Three.js, Python/JAX, API and asset pipeline stay in place.
No graphics-engine replacement, new numerical solver, source/load relaxation or
automatic construction variant is admitted. Full WO-03/04/05 and all physical,
paid-run, WO-10 review and flight-release gates remain open as recorded.
