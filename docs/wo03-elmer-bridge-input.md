## V2 input-only correction

After the primary’s explicit one-time correction, v2 compares serialized mesh integrals against the saved mesh-integrated sums using the original strict `1e-8` relative/absolute guard, and separately applies the existing 1% mesh-to-CAD criterion. Both checks pass for all seven regions. G11 serialized mesh 5501.023169933384 mm³ differs from saved mesh by +1.412e-9 mm³; its CAD difference is +4.54675e-6 relative. All three serialized washer areas differ from saved mesh by less than 2.58e-10 mm² and from exact CAD by about 4.97814e-5 mm², within the unchanged 0.0002 mm² area guard. Minimum sampled quadratic Jacobian is positive (0.00086392395 mm³), and the used-node graph is one connected component.

The explicit old-to-new map retains 42,715 used nodes and removes 135 nodes only after proving none is loaded or supported. All 1,574 support nodes are covered by 694 external support faces.
