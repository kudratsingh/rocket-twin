## Outcome and inspected starting evidence

The owner can distinguish drawing layers, identify the selected source component,
reveal a hidden selected part, focus its supplied dimensions and inspect it alone
without changing the physical source. Returning to context preserves the shared
visibility choices. Source role and simplified drawing representation are separate
labels; neither establishes manufactured geometry or physical qualification.

The existing offline image
`output/focused-design-2d/g80-reference-source-dimensions.png` was opened and
inspected before editing. Its configuration/hash caption was readable. Many small
overlapping envelopes had no legend, and the selected fin had no dedicated
callout. This is an observation of that offline image, not a browser observation.
The changes add an export-safe legend and selected annotation instead of changing
part dimensions or replacing the source with the current F2 engineering candidate.

## Implemented behavior

- The SVG carries layer names/counts, visible/hidden state, exact supplied source
  metadata, source-role and drawing-maturity labels, and unavailable geometry.
  Dashed envelope and gold selection meanings are written into the image.
- A gold selection frame is explicitly an annotation. It does not enlarge the
  source polygons. Small-part fit uses that part's own bounds; it does not include
  the nose datum or change dimensions to make the part appear larger.
- Source station labels follow the display transform. An offscreen nose datum
  is explicitly identified as outside the current view.
- Shared hidden parts and disabled drawing layers remain distinct. Reveal & focus
  restores the selected part through the existing shared visibility action and
  enables its layer. It does not reveal every hidden part or mutate the 3D camera.
- Selection-only mode reduces clutter. A persistent return-to-context button
  remains available even when selection changes to unavailable/hidden geometry.
- A native component picker provides a keyboard alternative to overlapping outlines.
  The SVG is keyboard-focusable: arrows pan the view, +/− zoom, F focuses/reveals,
  and R returns to context. Browser Ctrl/Cmd shortcuts remain unhandled. Events
  from active 2D controls do not command the retained hidden 3D camera.
- A selection absent from the displayed source produces a clear explanation and
  clear-selection action. It is never mapped onto another configuration.

## Files and integration contract

Updated `web/src/design/OrthographicDesign.tsx`, its scoped CSS and
`web/src/workspaces/DesignVisual.tsx`. Added `web/src/design/designPresentation.ts`
and `web/tests/design-presentation.test.mjs`. Existing orthographic source tests
remain applicable. No App/store/API, rendering-script, physical-source, workbench
or recorded drawing module was edited.

`OrthographicDesign` retains its three required props and adds optional
`hiddenPartIds?: readonly string[]` and `onRevealPart?: (id: string) => void`.
The owned `DesignVisual` already wires these to existing store actions; the primary
does not need to change shared contracts. Without a reveal callback, an externally
hidden component is clearly unavailable to the focus control until revealed by
its owning parts UI. Offline render callers can omit both optional props.

The standalone SVG viewport/export is now **1200 × 560**, including its legend
and provenance footer. Primary-owned raster scripts should respect this SVG
viewBox rather than hard-code the previous 520px height. Export cloning keeps
the SVG's inline drawing/legend styles and embedded source metadata.
